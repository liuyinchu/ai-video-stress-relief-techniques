# MiniMax分段配音稿

声线：平静、温暖的普通话女声。自然交谈、轻柔坚定，避免广告播音腔。每段单独生成；导出后保存为对应id音频。不要读编号标签、文件名和时长。

## intro / 4.5秒内

压力上来，先别急着说服自己。给身体一点缓冲。

目标：`assets/audio/voice/intro.wav`

## breath / 11.2秒内

一，鼻子吸气，再轻轻补一小口，嘴巴慢慢呼出。不要用力，头晕就停。

目标：`assets/audio/voice/breath.wav`

## cool / 5.3秒内

二，用凉毛巾轻敷脸颊，保持自然呼吸。

目标：`assets/audio/voice/cool.wav`

## ear / 4.3秒内

三，轻揉耳廓，以舒服为准。

目标：`assets/audio/voice/ear.wav`

## shake / 5.3秒内

四，轻轻抖动手脚，放松肩膀，别甩头。

目标：`assets/audio/voice/shake.wav`

## paper / 7.3秒内

五，把烦心事写下来，揉成纸团，再丢掉。

目标：`assets/audio/voice/paper.wav`

## nature / 6.3秒内

六，看一会儿树叶、云朵，让目光慢下来。

目标：`assets/audio/voice/nature.wav`

## order / 5.3秒内

七，只整理桌面一小块，让眼前恢复一点秩序。

目标：`assets/audio/voice/order.wav`

## outro / 6.0秒内

不必全做，挑一个就好。先松一口气，再处理眼前的事。

目标：`assets/audio/voice/outro.wav`
