# 《先松一口气》制作稿 v1

62 秒，30fps，1920×1080 横版及1080×1920竖版。七种动作都保留，但改成温和、可自主选择的小动作。不是要求观众在62秒内跟做完七项。

## 导演意图

所有章节位于同一面连续墙上。相机沿蛇形路径走过9个站点，墙上的连线、远处可见的邻站和统一纹理维持空间连续性。每次转场约0.8秒，停稳讲动作。双吸长呼段停留12秒；不加持续晃动。

横竖共享墙和内容，分别设定相机取景。文字和主体保持安全边距。轻微运动模糊用于移动，静止画面保留文字锐度。没有翻页、硬切或全屏卡片轮播。

## 内容修订

- 双吸长呼不宣称“最快重启”；不强行深吸，头晕就停。
- 冷水憋气改为凉毛巾轻敷、自然呼吸；不再称潜水反射教程。
- 耳部动作只说舒适触觉，不称迷走神经开关。
- 抖动改为温和松动，不甩头，不声称释放激素或创伤。
- 写下烦恼再揉团，避免“暴力发泄”解释。
- 看自然纹理不承诺降低60%压力。
- 整理只设定一个可完成的小范围。

具体证据与局限见 evidence.md。发布文案提示这些方法不保证立即见效。

## 声音

平静、温暖中文女声。MiniMax网页按段生成，分段文件可替换；配乐和音效用固定种子的程序合成，保留独立声部。底乐为柔和、缓慢的和声，动作处用小音效点到即止，语音出现时ducking。
